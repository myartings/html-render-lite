# 存在主义学习知识图谱

## 一句话理解

存在主义关心的是：当世界不再替你回答人生意义时，人如何通过选择、行动与承担来活出自己的意义。

## 核心节点

- 存在主义：中心主题。
- 荒诞：世界沉默与人追问意义之间的冲突。
- 自由：人无法逃避选择。
- 责任：选择之后必须承担后果。
- 本真：不躲进别人给的角色。
- 他人目光：自我在社会关系中被观看、评价和异化。

## 关键关系

- 荒诞 → 引出 → 反抗。
- 自由 → 导致 → 责任。
- 他人目光 → 威胁 → 本真。
- 尼采 → 影响 → 后来的存在主义问题意识。

## 记忆链

世界沉默 → 人追问意义 → 发现荒诞 → 仍然选择 → 承担责任 → 创造意义。

## 易混淆点

存在主义不是“人生没有意义所以随便活”，而是“没有现成意义，所以你更要为自己的选择负责”。

## 最小学习路径

1. 先读加缪《局外人》，感受荒诞。
2. 再读《西西弗神话》，理解荒诞与反抗。
3. 再读萨特《存在主义是一种人道主义》，理解自由与责任。
4. 最后回到尼采，理解价值重估与自我创造。

# 英语学习地图

## Metaphor
- type: city-map
- center: 口语广场
- goal: 迁移高地
- entry: 城门
- loop: 复习环线

## Nodes
- icon: 🏔
  title: 迁移高地
  role: goal
  desc: 真实沟通：技术讨论、旅行、面试、项目复述。
  tag: real task
- icon: 🗼
  title: 反馈塔
  role: feedback
  desc: 录音、转写、AI tutor、native feedback；一次只改 1–3 个关键问题。
  tag: correction
- icon: 🏛
  title: 阅读图书馆
  role: input
  desc: 高质量语料：AI、游戏开发、技术文章。读完产出一句 takeaway。
  tag: structured input
- icon: 🛠
  title: 写作工坊
  role: output
  desc: 慢速输出：英文日志、技术解释、改写句子。
  tag: slow output
- icon: 🌉
  title: 语法桥梁
  role: bridge
  desc: 只在表达卡住时修桥：时态、从句、语序、介词。
  tag: structure
- icon: 🗣
  title: 口语广场
  role: core
  desc: 城市中心：复述、shadowing、AI 对话。目标是能连续说 60–90 秒。
  tag: fluent output
- icon: ⚓
  title: 听力港口
  role: input
  desc: 真实语音流：先听主线，再听细节，字幕只做校验。
  tag: speech flow
- icon: 📦
  title: 词汇仓库
  role: review
  desc: 659 词不是库存，是 chunk 补给：短语、句型、自己的例句。
  tag: SRS chunks
- icon: 🚪
  title: 城门
  role: entry
  desc: 每天 10 分钟低摩擦入口：podcast、短文、视频、AI 对话。
  tag: daily entry

## Danger Zone
- 只收藏不复习
- 只背单词不输出
- 只看字幕不听音

## Daily Route
城门 10 分钟 → 听/读输入 → 词汇仓库补 10 个 chunk → 口语广场复述 3 分钟 → 反馈塔改 1–3 个错误 → 复习环线回收。

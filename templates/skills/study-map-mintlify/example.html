Flow

从想法到可验证产品

更稳的流程不是“想到就生成”，而是让判断跑在代码前面。

1

问题证据

先确认痛点、用户和失败风险，不要让 AI 为错误前提写代码。

2

MVP 边界

明确只验证什么；默认砍功能，避免零阻力范围蔓延。

3

上下文准备

提供 PRD、参考 App、截图、官方文档、开源实现和约束。

4

Agent 实现

让 Claude Code / Codex / prompt-to-app 工具快速产出原型。

5

真实验证

跑构建、测试、真机/浏览器、用户任务，不只看 demo。

6

结构判断

审查模块边界、数据模型、状态、权限和维护成本。

7

沉淀 Harness

把错误、验收标准、不变量、回归样本固化。

8

决定升级

原型继续 vibe；生产功能转 Agentic Engineering。

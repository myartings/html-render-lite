Action Ladder / Feedback Test

10 分钟写输入输出和验收标准；1 小时让 Agent 小步实现并跑测试；1 天沉淀失败样本；1 周固化成 skill / playbook / KB 页面。

Feedback Loop

输入选一个真实小需求，写清验收标准。
重构让 Agent 复述任务、风险和文件路径。
输出小步改代码或生成 artifact。
反馈跑测试、看 diff、做人工 review。
重复把失败样本写成下一轮 checklist。

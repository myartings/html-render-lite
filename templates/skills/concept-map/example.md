# 概念地图：三层五图法

## One Sentence
先让概念在现实中可见，再拆开它的组成与运作，最后把它放回更大的系统，理解它为什么存在。

## Layers

### 外显层
- purpose: 建立第一印象，避免一上来陷入抽象定义。
- diagram: 外显图：观察者在现实里看到的最小场景。
- questions: 它长什么样？别人如何观察到它？最小可见场景是什么？

### 内部层
- structure: 结构图：组成部分、边界、核心组件、外部依赖。
- mechanism: 动态机制图：输入 → 关键转换 → 输出 → 反馈/修正；这里必须解释“怎么用的”和“怎么跑起来”。

### 外部层
- position: 位置图：上位系统、同层相邻概念、下位分支、它解决哪一层的问题。
- environment-dynamics: 环境动力图：外部成因 → 张力/矛盾 → 概念出现 → 反过来改变系统。

## Examples

### vibe coding
外显层：人用自然语言描述需求，AI 读代码、改文件、跑命令，最后产出可运行功能。
内部层：LLM、上下文、工具、测试、反馈循环共同组成工作流。
外部层：LLM 代码能力提升、软件开发成本高、个人开发者想提高产出，推动了这种范式。

### 存在主义
外显层：一个人站在人生岔路口，没有外部说明书替他决定。
内部层：无预设意义 → 自由 → 选择 → 行动 → 责任 → 自我塑造。
外部层：宗教权威下降、现代性危机、战争经验和意义秩序崩塌，推动人重新追问“我该如何活”。

## Checklist
- 有没有先画出现实里的“什么样”？
- 结构图是否说明了组成和边界？
- 动态机制图是否解释了“怎么用/怎么工作”，而不只是“什么时候用”？
- 位置图是否说明它处在更大系统哪一层？
- 环境动力图是否说明它为什么出现、被什么推动、又推动什么？
- 是否区分内部动态和外部动力？
- 是否最后压缩成一个可复述的心智模型？

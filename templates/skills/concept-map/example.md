# 存在主义

## One Sentence
没有外部说明书替你决定人生时，你仍然必须选择，并为选择负责。

## Concrete Scenario
毕业后面对人生岔路口：进大厂、做独立开发、继续读博。每个选项都有代价，没有一个权威脚本能替你承担后果。

## Layers
### 外显层
- purpose: 先看见存在主义不是书斋抽象词，而是一个人面对无法外包的人生选择。
- diagram: 人站在岔路口，三条路径分别通往大厂、独立开发、读博。
- questions: 现实里它长什么样？谁在选择？选择之后谁承担？

### 内部层
- structure: 个体、自由、焦虑、选择、行动、责任、真实性、意义。
- mechanism: 无预设意义 → 自由显现 → 焦虑上升 → 选择 → 行动 → 承担后果 → 塑造自我。

### 外部层
- position: 用分层分类体系图呈现：Root System 是现代西方思想；主要分支包含现象学、存在主义、荒诞主义、虚无主义、人本主义心理学、现代文学/心理治疗；高亮存在主义分支，并展开克尔凯郭尔、萨特、波伏娃、加缪、雅斯贝尔斯，以及自由、选择、责任、真实性等核心议题。
- environment-dynamics: 宗教/传统权威下降、现代职业与生活路径变多、意义秩序松动，迫使个体重新回答“我该如何活”。

## Boundary
- 不是虚无主义：不是“什么都没有意义”，而是意义不能被预装。
- 不是任性自由：自由总是连着责任和后果。
- 不是消极悲观：焦虑是选择的信号，不是停止行动的理由。

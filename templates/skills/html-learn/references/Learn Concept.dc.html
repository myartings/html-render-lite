Reinforcement Learning from Human Feedback

RLHF

用人类对回答的相对偏好，把一个「会说话」的模型，调成一个「会给出人想要的回答」的模型。

真实场景 · 你早就在做的事 SCENE
“帮我把这封道歉邮件写得更真诚一点。”
回答 A
“抱歉给你带来不便，已按要求处理。”
回答 B ✓ 人更喜欢
“这次确实是我们的疏忽，给你添麻烦了。我已经……，并会……，避免再发生。”
你做的这个动作——在两个回答里挑更好的那个——就是 RLHF 的全部起点。
01 为什么重要

它解决的认知困惑

预训练模型「会说话」，但不知道什么是「好回答」。监督微调（SFT）能教它模仿示范答案，却无法表达「A 比 B 更好」这种相对判断——而人的偏好恰恰是相对的。

KEY INSIGHT
RLHF 把「人类的相对偏好」变成一个可优化的奖励信号，于是模型能朝「人更想要」的方向被持续推动，而不只是模仿一份标准答案。

03 实例走查

一条 prompt 的完整旅程

沿用上面那封道歉邮件，看它在 RLHF 训练里从触发走到结果。

  1. 1
    触发
    用户给出 prompt：「把道歉邮件写得更真诚」。
  2. 2
    生成
    策略模型产出多个候选回答（含 A、B）。
  3. 3
    打分
    奖励模型按「人会多喜欢」给每个回答打分——B 高于 A。
  4. 4
    更新 + 缰绳
    PPO 调整策略提高高分回答的概率，同时 KL 约束确保它别偏离原模型太远。
  5. ✓
    结果
    模型更稳定地给出像 B 那样、人类偏好的回答。
04 边界反例

它不是什么

最容易和 RLHF 混淆的三个邻居——看清区别才算真懂。

≠ SFT
监督微调
只模仿单一示范答案，学不到「A 比 B 好」的相对偏好。
≠ 纯 RL
环境奖励强化学习
奖励来自环境/规则；RLHF 的奖励来自人类偏好训练出的模型。
≈ DPO
直接偏好优化
同样用偏好数据，但跳过显式奖励模型与 RL——目标相近，机制不同。

06 心智模型
ONE-LINE MENTAL MODEL
把人类的相对偏好蒸馏成一把尺子（奖励模型），用它把模型往人想要的方向推，同时用 KL 缰绳拽住——别为了高分跑偏。
